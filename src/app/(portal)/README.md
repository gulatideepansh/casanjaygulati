# Portal Route Group

This route group is reserved for the future employee portal.

Planned modules:
- Employee login
- Role-based access control
- Staff dashboard
- Document access
- Internal notices
- Attendance
- Task management

Suggested future routes:

```text
src/app/(portal)
|-- login/page.tsx
|-- dashboard/page.tsx
|-- documents/page.tsx
|-- notices/page.tsx
|-- attendance/page.tsx
`-- tasks/page.tsx
```

Do not place public marketing pages here.
